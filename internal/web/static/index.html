    Forecast evolution

    How each provider's daily forecast for today evolved before midnight UTC. Lead time decreases from the oldest polls toward the target date.

    Select a location above to view forecast data.

    Each value represents one provider retrieval, grouped by provider and retrieval time. Chart lead time is measured to today's noon UTC; only forecasts retrieved at or before midnight UTC are included. Hourly (OpenWeatherMap: 3-hourly) data is aggregated over the UTC day. Partial coverage is flagged; missing values are not zero.

    The view refreshes every minute while active. All historical readings remain available via GET /api/v1/readings.
